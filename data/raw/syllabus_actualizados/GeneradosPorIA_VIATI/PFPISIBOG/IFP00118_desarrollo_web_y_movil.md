## 3. Descripción de la Unidad de Estudio

Con la tendencia global en el uso de Internet, una de las industrias que más profesionales está demandando en los últimos tiempos es el desarrollo de sitios Web y aplicaciones para móviles (llamadas comúnmente apps, por su abreviatura en inglés). El desarrollo de éstas es hoy en día la formación en informática que probablemente tenga más futuro profesional. Esta unidad de estudio dará a los estudiantes una comprensión más profunda de la arquitectura necesaria para construir aplicaciones basadas en Internet, incluyendo herramientas como servidor web, sistema de gestión de bases de datos y editores de código fuente. También proporciona un fondo básico en los fundamentos del diseño para construir sus propios sitios Web usando tecnologías tales como HTML, CSS y XML que le dará a los estudiantes mejor control sobre el desarrollo corporativo y/o de sus propios sitios Web. (Presente en plan: PFPISIBOG004)

## 4. Resultado de Aprendizaje de la Unidad

Aplica los diferentes lenguajes que se utilizan en diseños interactivos como HTML, CSS, XML y los fundamentos de JavaScript para el desarrollo de aplicaciones web o móvil con base en los requerimientos de la organización.

## 5. Contenidos de la Unidad de Estudio

### Por semestre (18 semanas) / Por ciclo (9 semanas) / Por módulo (4.5 semanas)
* **Conceptos Básicos de Tecnologías Web y Tecnologías del lado del servidor**
  * Introducción a la arquitectura cliente-servidor y protocolo HTTP.
  * Servidores Web, sistemas de gestión de bases de datos relacionales y editores de código fuente.
* **Diseño Web y Programación en HTML, CSS, XML y JavaScript**
  * Estructuración de documentos y marcado con HTML y XHTML.
  * Hojas de estilo en cascada (CSS) para diseño visual interactivo.
  * Fundamentos de lógica y programación del lado del cliente mediante JavaScript.
  * Uso de XML para la transferencia y estructuración de datos.
* **Publicación y Administración**
  * Despliegue de sitios en servidores web y administración de recursos de información.
